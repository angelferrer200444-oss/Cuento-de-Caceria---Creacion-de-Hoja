## 🎯 Propósito

**Cuentos de Cacería: Creación de Hoja** es una herramienta web diseñada para facilitar la creación y personalización de personajes para *Cuentos de Cacería*.

Su objetivo es reunir la información necesaria para preparar un Cazador sin tener que completar manualmente cada apartado de la hoja desde cero.

La aplicación permite seleccionar arquetipos y oficios, consultar sus datos asociados, personalizar las características del personaje y trasladar la información a una ficha RPG editable.

Además de facilitar este proceso, el proyecto busca ofrecer una experiencia visual coherente con la ambientación del juego, incorporando elementos de fantasía oscura, animaciones y efectos inspirados en los cuentos y las historias de cacería.

> 📚 **Importante:** esta herramienta sirve como apoyo para crear y organizar personajes. La guía del juego sigue siendo necesaria para consultar las reglas completas y comprender el significado de las habilidades, condiciones y demás elementos del sistema.

## 🧭 ¿Cómo funciona?

El proceso de creación está organizado para acompañar al usuario desde la selección inicial hasta la personalización de su ficha.

1. **🏰 Portada:** presenta la ambientación visual y permite acceder al proceso de creación.
2. **🎲 Modalidad de creación:** permite elegir entre crear un personaje manualmente o utilizar la generación aleatoria.
3. **🧬 Arquetipo:** carga automáticamente la información asociada al arquetipo elegido, incluidas sus descripciones, habilidades, peculiaridades, restricciones y valores iniciales.
4. **⚔️ Oficio:** presenta los datos relacionados con el oficio seleccionado, sus rutas de habilidades, hazañas y equipamiento. También permite añadir habilidades y equipo.
5. **🧠 Rasgos adicionales:** permite completar otros aspectos del personaje, como sus características, fobia y efecto narrativo.
6. **🕯️ Elementos opcionales:** ofrece apartados para añadir una maldición, un vicio y otros datos disponibles.
7. **📖 Identidad y origen:** permite introducir la información del Cazador, los datos del jugador y sus cuentos de origen.
8. **📄 Ficha final:** tras guardar la hoja, los datos se trasladan a una ficha RPG dinámica en la que se puede editar la información, incorporar un retrato y exportar el resultado en PDF.

### 🎲 Generación aleatoria

La modalidad aleatoria permite obtener una selección inicial de arquetipo, oficio y fobia sin tener que elegir cada elemento manualmente.

Una vez generados estos datos, el usuario puede revisar y personalizar los campos disponibles antes de guardar la hoja.

### ⚙️ Funcionamiento interno

Las opciones y sus datos están organizados en archivos JavaScript independientes. Los scripts responden a los cambios de los selectores y actualizan los campos relacionados.

El flujo básico utiliza tecnologías del lado del cliente, sin necesidad de un servidor propio para la creación de personajes.

> 📁 Esta representación resume los directorios y archivos principales. Puede haber otros recursos, scripts y documentos dentro de cada carpeta.

### ¿Qué contiene cada directorio?

- **`index.html`**: portada y punto de entrada de la aplicación publicada.
- **`templates/`**: páginas HTML de la aplicación, incluido el creador de personajes.
- **`static/css/`**: hojas de estilo de la interfaz, formularios y componentes visuales.
- **`static/js/`**: lógica de la portada, creación de personajes, datos de arquetipos, oficios, fobias y otras interacciones.
- **`static/images/`**: imágenes de portada, versiones para móviles y propuestas visuales.
- **`pre-creator/`**: pantalla previa para acceder a las modalidades de creación.
- **`dados20/`**: recursos de la experiencia de dados animados en 3D.
- **`ficha_rpg_dinamica/`**: ficha editable del personaje y sus opciones de exportación.
- **`fondo/`**: experiencia visual dedicada a la ambientación.
- **`documentacion/`**: material de referencia relacionado con el juego.
- **`.github/`**: plantillas para reportar errores, proponer mejoras y preparar contribuciones.

## 💻 Uso local

Si deseas ejecutar el proyecto desde tu computadora, puedes hacerlo siguiendo estos pasos.

### Requisitos

- Un navegador web actualizado.
- Una copia del repositorio.
- No es necesario instalar dependencias para probar el flujo básico de las páginas estáticas.

### Pasos

1. Descarga el repositorio desde GitHub o clónalo con Git.
2. Conserva la estructura de carpetas y archivos.
3. Abre `index.html` en un navegador.
4. Pulsa **Empezar** para acceder a las opciones de creación.
5. Selecciona la creación manual o la generación aleatoria.
6. Completa los campos disponibles y guarda la hoja.
7. Continúa en la ficha dinámica para editar la información, incorporar un retrato y utilizar las opciones de exportación disponibles.

También puedes abrir directamente `templates/creador.html` para acceder al formulario, siempre que las rutas y los recursos necesarios estén correctamente disponibles.

> 💡 **Consejo:** si alguna función o ruta no se comporta como esperas al abrir los archivos directamente, prueba el proyecto desde GitHub Pages o mediante un servidor web local. El comportamiento puede variar según el navegador y la forma en que se abran las páginas.

### 💾 ¿Cómo se conservan los datos?

Al guardar la hoja, la información del personaje se almacena temporalmente mediante el almacenamiento local del navegador (`LocalStorage`) y se utiliza para trasladarla a `ficha_rpg_dinamica/index.html`.

Desde la ficha dinámica es posible editar los campos disponibles, añadir un retrato y utilizar la opción de exportación en PDF.

Como el almacenamiento es local, los datos no deben considerarse una copia de seguridad permanente: borrar los datos del sitio o utilizar otro navegador o dispositivo puede impedir recuperarlos.
